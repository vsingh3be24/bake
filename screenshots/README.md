## Re-capturing

They're regenerated by driving the real app in headless Chromium — no manual
screenshotting. Start the seeded backend and the dev server, then run a
Playwright script that logs in as the owner and walks the routes above.
Two things matter if you redo it: pause CSS animations before shooting
(Framer Motion fades and the marquee never settle on their own), and put
live orders on *today's* delivery date or the kitchen queue renders empty.
